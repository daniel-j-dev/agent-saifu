SAIFU APP DESIGN

Extract this ZIP and open index.html in your browser. No installation or build step is required.

Edit index.html, style.css, and app.js in VS Code or another text editor.

Use demo as the password for action approvals. All wallet data, transactions, connections, and agent responses are simulated. No real keys are generated and no funds are moved.

The design stays vertical on mobile and desktop. Google Fonts requires internet access; system fonts are used otherwise. Clipboard features may require HTTPS or localhost.

Optional local server: run python3 -m http.server 8000 in the extracted folder, then open http://localhost:8000.
